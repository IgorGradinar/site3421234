Урок 6.4: Обзор библиотек

Модуль 6 ⏱️ ~1.5 часа

SkiaSharp

SkiaSharp — кроссплатформенная библиотека для 2D графики, основанная на Google Skia.

  • Преимущества: Высокая производительность, кроссплатформенность, современный API
  • Использование: Мобильные приложения, веб-приложения, высокопроизводительная графика
  • Установка: NuGet пакет SkiaSharp

ImageSharp

ImageSharp — современная библиотека для обработки изображений в .NET.

  • Преимущества: Чистый API, хорошая производительность, поддержка различных форматов
  • Использование: Обработка изображений, создание миниатюр, фильтры
  • Установка: NuGet пакет SixLabors.ImageSharp

OpenTK (OpenGL)

OpenTK предоставляет обертку для OpenGL в .NET.

  • Преимущества: Доступ к OpenGL, 3D графика, высокая производительность
  • Использование: 3D приложения, игры, научная визуализация
  • Установка: NuGet пакет OpenTK

Когда использовать что

Библиотека Когда использовать
GDI+ Windows Forms приложения, простая графика
SkiaSharp Кроссплатформенные приложения, высокая производительность
ImageSharp Обработка изображений, серверные приложения
OpenTK 3D графика, игры, научная визуализация

Практическое задание

Задание: Изучение библиотек

  1. Изучите документацию SkiaSharp или ImageSharp
  2. Создайте простое приложение, демонстрирующее возможности библиотеки
  3. Сравните с GDI+
