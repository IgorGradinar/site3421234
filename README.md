# 📚 Графическое программирование на C#

Полный онлайн-курс по созданию графических приложений на C# с использованием GDI+ и Windows Forms.

## 🎯 О курсе

Этот курс научит вас:
- Создавать красивые графические приложения на C#
- Работать с графическими компонентами (Graphics, Pen, Brush, Bitmap)
- Рисовать фигуры, текст и изображения
- Оптимизировать производительность (double buffering)
- Создавать анимацию и интерактивные эффекты
- Разрабатывать графики, диаграммы и визуализации

## 🚀 Быстрый старт

### 1. Локальное использование

Просто откройте файл `index.html` в браузере:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 2. Развертывание на сервер

Загрузите все файлы (кроме папки `extras/`) на ваш веб-сервер:
```bash
# Скопируйте файлы
cp -r * /var/www/course/ 2>/dev/null || xcopy * "D:\www\course\" /S

# Убедитесь что структура сохранена
```

### 3. С Python сервером (для тестирования)

```bash
# Python 3.x
python -m http.server 8000

# Затем откройте http://localhost:8000 в браузере
```

## 🔧 Установка и настройка

### Быстрая настройка для разработки

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd КУРС
```

2. (Опционально) Установите Python для локального сервера:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3. Запустите сервер:
```bash
python -m http.server 8000
```

4. Откройте http://localhost:8000 в браузере

## 🐛 Известные проблемы и совместимость

| Проблема | Решение |
|----------|---------|
| Изображения не загружаются | Убедитесь что папка `images/` на месте |
| JavaScript не работает | Проверьте что JavaScript включен в браузере |
| Стили неправильные | Очистите кэш браузера (Ctrl+F5) |
| Проблемы в IE11 | Используйте современный браузер (Chrome, Firefox, Edge) |
